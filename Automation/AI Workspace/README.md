# Local AI Workspace

This folder contains the local AI integration layer for the halal-trading-os Obsidian vault.

## Components

- System — AI policies and configuration
- Memory — durable AI memory
- Retrieval — local knowledge retrieval
- Skills — reusable AI workflows
- Tools — local tools and MCP integrations
- Logs — AI operation and diagnostic logs

The Obsidian vault remains the primary source of truth.
