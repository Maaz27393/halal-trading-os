# Intraday SOP

## 1. Pre-Trade

### Style Selection

- Intraday style is selected the night before.
- Style is never decided mid-session.

### Market Go / No-Go

Check:

1. NSE Advance > Decline
2. India VIX < 20
3. Nifty 50 trend positive
4. Stock EMA20 > EMA50

Scoring:

- 4/4 = Strong Go
- 3/4 = Go if setup is strong
- 2/4 = Caution; exceptional setups only
- 0–1/4 = Avoid

### Stock Selection

Use the curated Breakout Confirmation watchlist.

Nightly pipeline:

Institution Accumulation
→ 120-Day High
→ Volume Range Expansion
→ Breakout Confirmation

Do not revert to the retired two-scan workflow.

## 2. Intraday Time Windows

- 9:15–12:30 = Primary
- 12:30–1:30 = No-trade / A+ only
- 1:30–3:00 = Secondary
- 3:00+ = No fresh intraday entry

## 3. Entry Workflow

1. Stock hits Breakout Confirmation scanner.
2. Open chart.
3. Draw Anchored Volume Profile (AVP).
4. Wait for pullback + bullish confirmation candle on 15-minute chart.
5. Drop to 5-minute chart.
6. Enter using the Long Position tool.
7. Set target using Pivot Points Standard → next resistance.
8. Optional: check 3-minute chart for candle-reversal confirmation.

## 4. Entry Requirements

Before entry confirm:

- Stock is on the current Halal Stocks list.
- Market condition has been checked.
- Pullback confirmation is present.
- Required confluence is present.
- R:R ≥ 1:1.5.
- Risk ≤ 1% of applicable capital.
- Stop-loss is defined.
- Target is defined.

## 5. Halal Compliance

- Confirm the stock is on the current approved Halal Stocks list.
- No fresh Shariah re-screen is required if the stock is already on the approved list.

## 6. Stop-Loss and Target

- Set SL and target at entry, before execution.
- Anchor SL/TP to the actual fill price.
- Never anchor SL/TP to `close`.
- Target = Pivot Points Standard next resistance level.

## 7. Position Sizing

- Maximum risk = 1% of applicable capital.
- Maximum = 2 positions per day globally.
- Second trade uses only remaining available capital.
- No leverage or margin.

## 8. In-Trade Behavioral Check

### Matrix Technique

Ask:

> "Am I following my plan?"

If **No**:

- Exit immediately.
- Stop trading for the day.

## 9. Exit Sequence

Exit at whichever occurs first:

1. Predefined Stop-Loss
2. Predefined Target
3. Matrix Technique behavioral trigger

### Not Currently Approved

- Intraday trailing stop
- Intraday partial-profit mechanism

These remain future research items and are not active SOP rules.

## 10. Post-Trade Logging

Record the trade according to the Trading Journal specification.

For Intraday, record applicable fields including:

- VWAP confirmation
- AVP used
- RSI-10 band
- Duration
- Matrix Technique check
- Star Points earned

## 11. Intraday Never-Do Rules

- Never take a fresh intraday entry after 3:00 PM.
- Never risk more than 1% on a single stock.
- Never act on emotion without the Matrix Technique check.
- Never use leverage, margin, F&O or short positions.
- Never trade a non-Halal-screened stock.

## 12. Future Research

### Intraday Trailing Stop / Partial Profit

Not currently approved.

Intraday remains governed by:

- Predefined SL
- Predefined Target
- Matrix Technique

Any future change requires:

Research → Evidence → Decision → Trading System update

## SOP Authority

This SOP documents execution of approved Trading System rules.

It must not create or independently modify Trading System rules.
